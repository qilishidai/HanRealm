# 汉境（HanRealm）—— J2ME → Python 移植版

一款从 **J2ME/MIDP-2.0** 手机游戏移植到 **Python 3 + pygame** 的回合制策略游戏。
原版运行在诺基亚 S60 手机（176×208 小屏），本移植用 pygame 复刻，并在现代屏幕上**放大 2 倍**显示。

> 游戏主题：回到两千年前的西域，指挥大汉王朝逐步击败匈奴等势力。共 6 关战役，含城市建设、部队训练、外交、贸易、任务系统。

---

## 一、环境要求

- **Python 3.7+**
- **pygame 2.1+**（安装：`pip install -r requirements.txt`）

## 二、如何运行

在项目根目录（`HanRealm`）下：

```bash
python 汉境.py
```

或者进入 `汉境` 包目录后：

```bash
python 主程序.py
```

运行后会出现一个 **352×416** 的窗口（原版逻辑分辨率 176×208，放大 2 倍）。

## 三、操作说明

| 操作 | 键盘 | 原版按键 | 对应功能 |
|------|------|---------|---------|
| 上/下/左/右移动 | 方向键 | 方向键 | 移动光标 |
| 确定 | `Enter` / `空格` | 中央确定键 | 确认 / 选择 |
| 左功能键（菜单） | `A` 或 `M` | 左软键 | 弹出游戏/城市菜单 |
| 右功能键 | `B` 或 `Esc` | 右软键 | 取消 / 返回 |
| 数字 1/2/3/4 | `1` `2` `3` `4` | 数字键 | 快捷选择（下一城/下一部队/游戏菜单/上一城） |

**游戏流程**：
1. 启动画面按任意键进入主菜单。
2. 主菜单：`继续游戏`（读档）/ `新游戏` / `帮助` / `制作组` / `退出`。
3. 进入关卡后，把光标移到己方城市上按 **确定**，弹出城市菜单（制造/信息/城市/外交）。
4. 把光标移到空地/建筑上按 **确定**，弹出对应操作菜单（建造、回合结束等）。
5. 选定目标后按 **左功能键** 执行，移动部队用方向键。

## 六、移植说明与验证

**移植要点**：
- 保留原版**所有算法与数值**（兵种属性、建筑效果、外交矩阵、任务条件等），逐行对应。
- 原版屏幕 176×208 被保留为逻辑坐标系；绘制到离屏画布后整体放大 2 倍显示。
- 地图数据仍是**位打包 int**（低 8 位地形 / 8-15 位物体 / 16-23 位归属 / 24-30 位部队ID / 31 位高亮）。
- 存档由原 RecordStore 二进制改为本地文件 `china.dat`，用 `数据流.py` 保持与 Java `DataInputStream/OutputStream` 完全一致的有序二进制格式。
- `res/data.png` 其实**不是图片**，而是二进制关卡包，由 `关卡数据.py` 解析。

**已验证**：
- ✅ 全部模块语法编译通过、导入成功。
- ✅ 6 关关卡数据全部正确解析（城名/地图尺寸/任务文本）。
- ✅ 启动画面、主菜单、城市/部队精灵、等距地图、状态栏、生产菜单、外交列表均能正确渲染（见上方截图）。
- ✅ 主菜单 → 新游戏 → 加载第 1 关 → 城市菜单 → 回合结束 全流程跑通、无崩溃。
- ✅ 存档/读档往返一致（1.2KB，地图/城市/部队状态完全恢复）。
- ✅ 120 帧压力测试（轮换各种按键）零错误。

## 七、如何从源码看移植对应关系

原版 J2ME 源码保留在 `src/` 目录（Java），可对照阅读。为便于对照，本移植在关键方法处保留了原方法的注释（如 `# 对应原 Game.drawMap`）。

文件对照：
- `src/core/Game.java` → `汉境/游戏.py`
- `src/core/City.java` → `汉境/城市.py`
- `src/core/Unit.java` → `汉境/部队.py`
- `src/core/Menu.java` → `汉境/菜单.py`
- `src/core/GameScreen.java` → `汉境/游戏界面.py`
- `src/core/CatMid.java` → `汉境/主程序.py`
- `src/com/nokia/.../*.java`（Nokia 桩）→ 由 pygame 直接替代（`图形.py`/`音效.py`/`输入.py`）
